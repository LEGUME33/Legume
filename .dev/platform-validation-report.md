## 一、今日热点页面（新增 · 学习模块最后一个子页）
- **内容推送逻辑**：按当前学习计划主题（AI / 产品经理 / 大数据模型）每日「确定性」自动推送 **5 条**外部热点链接。
  - 实现：`HOTSPOT_POOL` 主题外链池（每个主题 10 条真实可跳转外链）+ FNV-1a 日期种子 `seededShuffle` → 同主题、同一天推送结果稳定不漂移。
  - 链接为 `<a href target=_blank>`，点击直接跳转对应网页。
- **阅读状态交互**：每条热点前置勾选框，勾选「已读」后整条文字自动变灰 + 删除横线（复用全站统一 `.tl-task.is-done` 态）。
  - 已读/待读状态经 `TL.Store.update` 持久化至 `localStorage` + GitHub `data/study.json`，双端长期存档。
- **修复生产级 re-entrancy bug**：原实现每条热点单独 `TL.Store.update`，而 `app.js` 的「数据变更→重绘当前页」监听会在渲染中途再次重绘 → 热点反复叠加到 15+ 条。
  - 修复：①`ensureDailyHotspots` 收集后一次性批量写入；②`renderHotspots` 加重入保护 flag。修复后 store/DOM 均精确 **5 条**。
